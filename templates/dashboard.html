Usage examples

Fetch every code:

curl -H "X-API-Key: {{ api_key_prefix }}…" \
  {{ request.base_url }}api/v1/totp/codes

Fetch a single code by entry id:

curl -H "X-API-Key: {{ api_key_prefix }}…" \
  {{ request.base_url }}api/v1/totp/<entry_id>/code

Fetch the first code for a given issuer:

curl -H "X-API-Key: {{ api_key_prefix }}…" \
  {{ request.base_url }}api/v1/totp/code/by-issuer/GitHub
